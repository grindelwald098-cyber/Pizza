# Инструкции для агента

## Коммиты

В конце каждой завершённой правки создавай отдельный git-коммит только с файлами этой правки, чтобы по истории было видно, что изменилось.

- Сообщение — 1–2 предложения: что сделано и зачем.
- Если изменений нет, пустой коммит не создавай.
- Не добавляй `Co-authored-by` и не указывай агента соавтором. В сообщении коммита нет подписи агента.
- Не меняй git config. Не используй `--no-verify`, force push и `amend`, если пользователь явно этого не просил.
- Не коммить секреты: `.env`, ключи, пароли.

Пример сообщения:

```
Вынести общий CRUD справочников и синхронизацию связей товара.

Повторяющиеся сервисы и обновление размера, теста и состава больше не копируются.
```
